====================================================================
 КАК ДОБАВИТЬ (ИЗМЕНИТЬ / УДАЛИТЬ) МАШИНУ В РАЗДЕЛЕ «ОРЕНДА АВТО»
====================================================================

Все машины хранятся в ОДНОМ файле: cars.json (лежит в папке сайта).
Страница orenda.html читает этот файл и сама рисует карточки.
Менять вёрстку (HTML) не нужно — только этот файл.


--------------------------------------------------------------------
1. ЧТО ОТКРЫТЬ
--------------------------------------------------------------------
Откройте файл cars.json любым текстовым редактором
(Блокнот, Notepad++, VS Code).

Внутри — список машин в квадратных скобках [ ... ].
Каждая машина — это блок в фигурных скобках { ... }, а между
машинами стоит запятая.

Схематично:
[
  { ... машина 1 ... },
  { ... машина 2 ... },
  { ... машина 3 ... }
]


--------------------------------------------------------------------
2. КАК ДОБАВИТЬ НОВУЮ МАШИНУ
--------------------------------------------------------------------
1) Скопируйте целиком блок любой машины — от { до } .
2) Вставьте его в конец списка, ПЕРЕД закрывающей скобкой ].
3) Поставьте запятую после предыдущего блока (перед вставленным).
4) Замените значения в кавычках на данные новой машины.
5) Сохраните файл (Ctrl+S).
6) Обновите страницу в браузере (Ctrl+F5).

ВАЖНО про запятые:
- Между машинами запятая СТОИТ.
- После ПОСЛЕДНЕЙ машины запятой НЕТ.


--------------------------------------------------------------------
3. ШАБЛОН ОДНОЙ МАШИНЫ (копируйте это)
--------------------------------------------------------------------
  {
    "id": "toyota-corolla-aa1234",
    "brand": "Toyota",
    "model": "Corolla",
    "year": 2018,
    "category": "Комфорт",
    "fuel": "Гібрид",
    "fuelTags": ["Гібрид"],
    "gearbox": "Автомат",
    "pricePerWeek": 4000,
    "deposit": 6000,
    "photos": ["corolla-aa1234-1.jpg", "corolla-aa1234-2.jpg"],
    "features": ["Кондиціонер", "Дитяче крісло"],
    "requirements": [
      "Вік від 25 років",
      "Стаж водіння від 3 років",
      "Оренда мінімум 1 місяць"
    ]
  }


--------------------------------------------------------------------
4. ЧТО ОЗНАЧАЕТ КАЖДОЕ ПОЛЕ
--------------------------------------------------------------------
"id"           — уникальная метка машины. Придумайте любую (удобно
                 использовать госномер или внутренний код).
                 У ДВУХ машин id не должны совпадать.

"brand"        — марка (Toyota, Peugeot, Škoda, Volkswagen …).
"model"        — модель (Corolla, 308 SW, Octavia …).
"year"         — год выпуска, число без кавычек (2018).
"category"     — класс авто. Ровно одно из:
                 "Стандарт", "Комфорт", "Бізнес", "Black/Premium".

"fuel"         — как тип топлива ПОКАЗЫВАЕТСЯ в карточке
                 (можно текстом, например "Гібрид / Газ / Бензин").

"fuelTags"     — теги топлива ДЛЯ ФИЛЬТРА (список в кавычках).
                 Разрешённые значения:
                 "Бензин", "Дизель", "Гібрид", "Газ", "Електро".
                 Можно несколько: ["Гібрид", "Газ", "Бензин"].

"gearbox"      — коробка: "Автомат" или "Механіка".
"pricePerWeek" — цена за неделю, число без кавычек (4000).
"deposit"      — депозит, число без кавычек (6000).

"photos"       — список файлов фото (в кавычках, через запятую).
                 Файлы кладите в ту же папку сайта.
                 Если фото одно:      ["corolla.jpg"]
                 Если несколько:      ["corolla-1.jpg", "corolla-2.jpg"]
                 (тогда в карточке появятся стрелки ‹ › для листания).

"features"     — особенности ДЛЯ ФИЛЬТРА (список в кавычках).
                 Разрешённые значения:
                 "Кондиціонер", "Дитяче крісло",
                 "Брендування таксі", "Оренда з викупом".

"requirements" — требования к водителю (список строк).
                 Показываются по кнопке «Умови» в карточке.


--------------------------------------------------------------------
5. КНОПКА «УМОВИ» НА КАРТОЧКЕ
--------------------------------------------------------------------
Текст, который открывается по кнопке «Умови», берётся из поля
"requirements" этой же машины. Каждая строка списка = один пункт
(маркированный) в блоке «Вимоги до водія».

Пример в cars.json:

    "requirements": [
      "Вік від 25 років",
      "Стаж водіння від 3 років",
      "Оренда мінімум 1 місяць"
    ]

Так это покажется на карточке под кнопкой «Умови»:

    Вимоги до водія:
     • Вік від 25 років
     • Стаж водіння від 3 років
     • Оренда мінімум 1 місяць

Чтобы ДОБАВИТЬ пункт  — допишите новую строку в кавычках через запятую.
Чтобы ИЗМЕНИТЬ пункт  — поправьте текст внутри кавычек.
Чтобы УБРАТЬ пункт    — удалите эту строку.

Правила те же: строки в кавычках, между пунктами запятая, после
последнего пункта запятой нет. Порядок строк = порядок на карточке.

Примечание: «Умови» — это СПИСОК коротких пунктов (требований).
Если написать одну длинную фразу — она станет одним большим пунктом.


--------------------------------------------------------------------
6. НЕСКОЛЬКО ОДИНАКОВЫХ МАШИН (одна марка/модель/год)
--------------------------------------------------------------------
Это нормально. Каждая машина — отдельный блок, они НЕ объединяются.
Просто дайте им РАЗНЫЕ "id" и РАЗНЫЕ файлы в "photos":

  { "id": "corolla-aa1234", ... "photos": ["corolla-aa1234.jpg"] },
  { "id": "corolla-bb5678", ... "photos": ["corolla-bb5678.jpg"] }

Фото берётся только из поля "photos" этой машины — путаницы не будет.


--------------------------------------------------------------------
7. КАК ИЗМЕНИТЬ ИЛИ УДАЛИТЬ МАШИНУ
--------------------------------------------------------------------
ИЗМЕНИТЬ: найдите нужный блок, поправьте значение (например цену),
          сохраните файл, обновите страницу.

УДАЛИТЬ:  удалите весь блок этой машины от { до } .
          Проверьте запятые: между оставшимися машинами — запятая,
          после последней — запятой нет.


--------------------------------------------------------------------
8. ЧАСТЫЕ ОШИБКИ (из-за них список может не загрузиться)
--------------------------------------------------------------------
- Забыли запятую между машинами  → добавьте её.
- Лишняя запятая после последней машины → уберите её.
- Пропущена кавычка "  или скобка } → допишите.
- Русская буква вместо латинской в названии поля
  (поля пишутся латиницей: "brand", "model", "year" и т.д.).
- Число в кавычках. Год/цена/депозит — БЕЗ кавычек: 2018, 4000.
  А текст (марка, модель) — В кавычках: "Toyota".

Если в файле ошибка — на странице появится сообщение
«Не вдалося завантажити список авто. Перевірте файл cars.json…».
Это подсказка, что где-то нарушен формат (обычно запятая/кавычка).

Совет: перед сохранением можно проверить файл на сайте
https://jsonlint.com — вставить содержимое и нажать «Validate».


--------------------------------------------------------------------
9. КОРОТКО (шпаргалка)
--------------------------------------------------------------------
1. Открыть cars.json
2. Скопировать блок { ... } существующей машины
3. Вставить перед ] , поставить запятую перед ним
4. Поменять значения (id, марка, модель, цена, фото …)
5. Положить фото в папку сайта
6. Сохранить (Ctrl+S) → обновить страницу (Ctrl+F5)
